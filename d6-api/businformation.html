정류장 표지판이나 네이버·카카오맵에 있는 5자리 번호예요.

🚌 버스 번호로 찾기

그 버스가 지나가는 모든 정류소의 도착 예정을 보여 줘요.

🔌 이 화면이 쓰는 API

🔑 서울시 버스 API는 서비스키가 필요해요. 키는 Vercel 서버에만 있고, 이 화면은 내 서버 창구(/api/bus)만 불러요. 그래서 아래 주소에도, 브라우저 개발자 도구에도 키가 보이지 않아요.

정류소 번호 → 오는 버스 (정류소정보조회)

아직 부르지 않았어요 새 탭에서 원본 JSON 보기 ↗

버스 번호 → 노선 ID (노선정보조회)

아직 부르지 않았어요 새 탭에서 원본 JSON 보기 ↗

노선 ID → 정류소별 도착 예정 (버스도착정보조회)

아직 부르지 않았어요 새 탭에서 원본 JSON 보기 ↗
